# E-Commerce Sales Analytics

## Project Overview

This project aims to build an end-to-end e-commerce sales analytics pipeline using Python, PostgreSQL, SQL, and Tableau.

The project will demonstrate how raw data can be collected from APIs and files, validated, transformed, stored, analyzed, and visualized to generate business insights.

## Business Objectives

* Analyze sales and revenue trends.
* Identify top-performing products and categories.
* Understand customer purchasing behavior.
* Compare regional sales performance.
* Monitor key business KPIs.
* Present insights through an interactive dashboard.

## Technology Stack

* Python
* Pandas and NumPy
* Requests
* PostgreSQL and SQL
* SQLAlchemy and Psycopg
* Matplotlib and Seaborn
* Tableau
* Git and GitHub

## Project Workflow

1. Business requirements
2. Data source selection
3. API and file ingestion
4. Raw data storage
5. Data quality checks
6. Data cleaning and transformation
7. PostgreSQL storage
8. SQL analysis and exploratory data analysis
9. KPI development
10. Tableau dashboard
11. Business insights
12. Testing and automation
